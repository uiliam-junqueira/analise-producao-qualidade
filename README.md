# 📊 Análise de Produção e Qualidade

## 🎯 Objetivo

Este projeto tem como objetivo analisar dados de produção industrial para identificar padrões de defeitos e possíveis causas, auxiliando na melhoria dos processos.

---

## 📂 Dados

O dataset contém informações como:

* Data
* Turno
* Máquina
* Produto
* Quantidade produzida
* Quantidade defeituosa
* Tipo de defeito
* Operador
* Tempo de parada

---

## 🧠 Análises Realizadas

* Cálculo da taxa de defeito
* Análise por máquina
* Análise por turno
* Análise por operador
* Cruzamento operador x máquina
* Gráfico de Pareto (tipos de defeito)

---

## 📊 Principais Insights

* A **Máquina A** apresentou maior taxa de defeitos (~8,4%)
* O **turno da manhã** teve maior índice de falhas
* A combinação **Maria + Máquina A** apresentou a maior taxa (~13,7%)

---

## 📈 Conclusão

Os resultados indicam que os defeitos não estão relacionados apenas às máquinas, mas também à operação, sugerindo necessidade de revisão de processos e treinamento.
